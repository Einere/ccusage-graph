# ccusage-graph

A CLI tool to visualize [ccusage](https://github.com/ryoppippi/ccusage) JSON reports as terminal graphs.

## Features

- Cost bar chart (daily / weekly / monthly)
- Token usage bar chart (daily / weekly / monthly)
- Cost breakdown by model
- Period summary (total cost, average, peak period, etc.)
- Auto-detects JSON format from top-level key (`daily`, `weekly`, `monthly`)

## Installation

```bash
npm install -g @einere/ccusage-graph
```

## Usage

First, generate a JSON report with [ccusage](https://github.com/ryoppippi/ccusage):

```bash
# daily (default)
ccusage --from 2026-01-19 --to 2026-02-18 --json > report.json

# weekly
ccusage --from 2026-01-19 --to 2026-02-18 --json --weekly > report_weekly.json

# monthly
ccusage --from 2026-01-19 --to 2026-02-18 --json --monthly > report_monthly.json
```

Then pass the JSON file to `ccusage-graph`:

```bash
ccusage-graph report.json
ccusage-graph report_weekly.json
ccusage-graph report_monthly.json
```

## Input JSON Format

Uses the JSON format generated by `ccusage` as-is. The tool auto-detects the format from the top-level key.

### Daily

```json
{
  "daily": [
    {
      "date": "2026-01-19",
      "totalTokens": 10412828,
      "totalCost": 7.34,
      "modelBreakdowns": [{ "modelName": "claude-opus-4-5-20251101", "cost": 7.11, ... }]
    }
  ],
  "totals": { "totalCost": 12.19, "totalTokens": 20300000, ... }
}
```

### Weekly

```json
{
  "weekly": [
    {
      "week": "2026-01-18",
      "totalTokens": 10412828,
      "totalCost": 7.34,
      "modelBreakdowns": [{ "modelName": "claude-opus-4-5-20251101", "cost": 7.11, ... }]
    }
  ],
  "totals": { "totalCost": 12.19, "totalTokens": 20300000, ... }
}
```

### Monthly

```json
{
  "monthly": [
    {
      "month": "2026-01",
      "totalTokens": 34720100,
      "totalCost": 26.04,
      "modelBreakdowns": [{ "modelName": "claude-opus-4-5-20251101", "cost": 25.46, ... }]
    }
  ],
  "totals": { "totalCost": 410.83, "totalTokens": 597631053, ... }
}
```
