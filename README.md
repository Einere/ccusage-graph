# ccusage-graph

A CLI tool to visualize [ccusage](https://github.com/ryoppippi/ccusage) JSON reports as terminal graphs.

## Features

- Daily cost bar chart
- Daily token usage bar chart
- Cost breakdown by model
- Period summary (total cost, daily average, peak day, etc.)

## Installation

```bash
npm install -g @einere/ccusage-graph
```

## Usage

First, generate a JSON report with [ccusage](https://github.com/ryoppippi/ccusage):

```bash
ccusage --from 2026-01-19 --to 2026-02-18 --json > report.json
```

Then pass the JSON file to `ccusage-graph`:

```bash
ccusage-graph report.json
```

## Input JSON Format

Uses the JSON format generated by `ccusage` as-is.

```json
{
  "daily": [
    {
      "date": "2026-01-19",
      "totalTokens": 10412828,
      "totalCost": 7.34,
      "modelBreakdowns": [
        {
          "modelName": "claude-opus-4-5-20251101",
          "inputTokens": 18196,
          "outputTokens": 526,
          "cacheCreationTokens": 394364,
          "cacheReadTokens": 9080364,
          "cost": 7.11
        }
      ]
    }
  ],
  "totals": {
    "totalCost": 12.19,
    "totalTokens": 20300000,
    "inputTokens": 50000,
    "outputTokens": 5000,
    "cacheCreationTokens": 1500000,
    "cacheReadTokens": 18000000
  }
}
```
